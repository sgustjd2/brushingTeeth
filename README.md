# 양치 연구소 · 아— 해봐요!

마우스·터치·키보드로 칫솔을 움직이는 반응형 HTML Canvas 양치 교육 프로토타입.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저에서 엽니다. GitHub Pages는 main 브랜치 루트에서 서비스합니다.

## 기능

- AI 생성 실사형 구강 이미지, 바깥면·안쪽면·어금니 씹는 면별 판정 영역
- 각 면과 부위에 독립적으로 유지되는 치태, 접촉 위치와 짧은 이동에 따른 제거
- 바깥면·안쪽 구치부 45°, 안쪽 앞니 90°와 수직 움직임, 씹는 면 0° 교육 설정
- 실제 경과시간 기준 2분 타이머, 일시정지, 페이지를 떠나면 자동 정지
- 면별 결과, 재시작, 치태 표시, 교육 가이드
- 모바일 하단 고정 0°·45°·90° 버튼, 시작/일시정지, 남은 시간, 제거율
- 모바일 터치와 키보드(방향키 이동, Space+방향키 양치)
- 외부 라이브러리, 추적, 개인정보 저장 없음

## 교육 범위

치아 형상·색·제거 속도·각도는 단순화한 학습 표현입니다. AI 이미지이므로 실제 환자 사진이나 정밀 해부학적 3D 모델, 압력 센서, 임상적으로 검증된 평가 도구가 아닙니다. 게임 점수는 충치 예방 효과나 실제 청결도를 측정하지 않습니다. 기존 충치는 양치로 제거되지 않습니다. 임상 교육에 활용하기 전 치과 전문가의 검토와 대상 연령에 맞는 안내가 필요합니다.

## 검증

Node VM으로 판정 영역 수, 접촉 시 치태 감소, 각도 불일치 시 제거 제한, 일시정지, 타이머 표시, 초기화를 확인했습니다. 실제 브라우저에서 화면, 모바일 390px 가로 넘침, 48px 터치 버튼, 각도 선택, 면 전환 시 권장 각도, 타이머, 일시정지와 결과 화면을 확인했습니다.
