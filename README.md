# 양치 연구소 · 아— 해봐요! · 주차 랩

같은 GitHub Pages 사이트에서 [주차 연습 게임](./parking.html)도 제공합니다. 항공뷰·운전석 뷰, 4단계 120개 주차 시나리오, 키보드·터치 조작을 사용할 수 있습니다.

마우스·터치·키보드로 칫솔을 움직이는 반응형 HTML Canvas 양치 교육 프로토타입.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저에서 엽니다. GitHub Pages는 main 브랜치 루트에서 서비스합니다.

## 기능

- AI 생성 실사형 구강 이미지, 바깥면·안쪽면·어금니 씹는 면별 판정 영역
- 각 면과 부위에 독립적으로 유지되는 치태, 드래그 경로 전체의 칫솔 접촉에 따른 제거, 소수점 제거율
- 바깥면·안쪽 구치부 45°, 안쪽 앞니 90°와 수직 움직임, 씹는 면 0° 교육 설정
- 치아 드래그 시 자동 시작/재개, 각도가 달라도 감소하며 권장 각도 안내
- 실제 경과시간 기준 2분 타이머, 일시정지, 페이지를 떠나면 자동 정지
- 면별 결과, 재시작, 치태 표시, 교육 가이드
- 모바일 하단 고정 0°·45°·90° 버튼, 시작/일시정지, 남은 시간, 제거율
- 모바일 터치와 키보드(방향키 이동, Space+방향키 양치)
- 외부 라이브러리, 추적, 개인정보 저장 없음

## 교육 범위

치아 형상·색·제거 속도·각도는 단순화한 학습 표현입니다. AI 이미지이므로 실제 환자 사진이나 정밀 해부학적 3D 모델, 압력 센서, 임상적으로 검증된 평가 도구가 아닙니다. 게임 점수는 충치 예방 효과나 실제 청결도를 측정하지 않습니다. 기존 충치는 양치로 제거되지 않습니다. 임상 교육에 활용하기 전 치과 전문가의 검토와 대상 연령에 맞는 안내가 필요합니다.

## 검증

Node VM으로 판정 영역 수, 접촉 시 치태 감소, 각도 불일치 시 감소와 피드백, 일시정지, 타이머 표시, 초기화를 확인했습니다. 실제 브라우저에서 화면, 모바일 390px 가로 넘침, 48px 터치 버튼, 각도 선택, 면 전환 시 권장 각도, 타이머, 일시정지와 결과 화면을 확인했습니다.

브라우저에서 시작 버튼 없이 치아를 드래그하여 제거율이 0.0% → 0.1% → 0.4%로 누적되는 것을 확인했습니다.

## 주차 랩

'parking.html'에는 기초 감각·공간 읽기·좁은 골목·실전 종합의 4단계가 있고, 각 단계에 30개씩 총 120개의 시나리오가 있습니다. 직각 후진, 평행, 사선, 좁은 칸, 기둥 옆, 경사로, 출차 동선 등의 패턴과 주차장·아파트 지하·주택가 골목·야간·비 노면 등의 조건을 조합합니다. 항공뷰에는 AI 생성 실사형 차량 스프라이트, 운전석 뷰에는 대시보드·앞유리 시야 이미지를 사용하며 방향키·조이스틱·D/R/브레이크 조작, 접촉·오차·정지 시간 기반의 학습 점수를 제공합니다. 차량·운전석 이미지는 실제 차량 카메라나 운전 능력 평가를 대체하지 않는 시각 자료입니다.
